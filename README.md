# SPORTIFY (Lapangan Kosong)

**Temukan Teman Olahraga Kapan Saja, Di Mana Saja**

Aplikasi yang menghubungkan orang-orang dengan minat olahraga yang sama untuk membuat atau bergabung ke event olahraga di sekitar mereka.

---

## 📋 Deskripsi

SPORTIFY adalah platform mobile yang mempertemukan pengguna dengan komunitas olahraga sesuai minat dan waktu, serta mendorong gaya hidup sehat dan aktif dengan cara yang menyenangkan dan sosial.

---

## 🎯 Latar Belakang

Banyak orang ingin berolahraga tapi sering kesulitan mencari teman yang mau diajak olahraga dadakan.

### Problem
- Sulit menemukan partner olahraga spontan
- Event olahraga lokal sering tidak terpublikasi dengan baik
- Kurangnya wadah untuk menggabungkan jadwal dan minat olahraga yang berbeda

### Tujuan Aplikasi
Menjadi platform yang mempertemukan pengguna dengan komunitas olahraga sesuai minat dan waktu, serta mendorong gaya hidup sehat dan aktif dengan cara yang menyenangkan dan sosial.

---

## ✨ Fitur Utama

### User/Member
- ✅ Menemukan event berdasarkan cabang olahraga
- ✅ Bergabung dengan olahraga sesuai minat
- ✅ Membuat event olahraga

### Admin Panel
- ✅ User Management
- ✅ Event Approval

### Dashboard
- Menampilkan list olahraga yang dapat dipilih dan diikuti
- Informasi user yang sedang login

## 🔄 User Flow

1. **Login/Sign up** - Registrasi atau masuk ke aplikasi
2. **Telusuri event yang tersedia** - Cari event olahraga berdasarkan cabang olahraga
3. **Buat event olahraga** - Membuat event olahraga baru
4. **Join event olahraga yang diminati** - Bergabung dengan event yang sesuai

## 🚀 Getting Started

### Prerequisites
- Flutter SDK
- Dart
- Android Studio / VS Code
- Emulator atau Physical Device

### Installation

1. Clone repository ini
```bash
git clone [repository-url]
cd mobile
```

2. Install dependencies
```bash
flutter pub get
```

3. Run aplikasi
```bash
flutter run
```
